# TetrAJ  
A simple, fast, and fun mobile game built with Unity and released for Android.  
TetrAJ focuses on quick reaction gameplay, smooth performance, and lightweight design — ideal for mobile users.
TetrAJ includes a fully custom-built global leaderboard system — no third-party services like Firebase or PlayFab were used

## 📝 Overview  
TetrAJ is a Unity-based mobile game developed as a solo project.  
The goal was to practice Unity gameplay mechanics, UI design, data storage, and publishing an Android build.

---

## Gameplay  
- Fast-paced, simple casual gameplay  
- Minimal UI and clean visual style  
- Easy touch-based controls  
- Designed to run smoothly on most devices  

---

## Custom Online Leaderboard System  
TetrAJ includes a fully custom-built global leaderboard system — no third-party services like Firebase or PlayFab were used. 

- Scores are uploaded automatically when online  
- If the player is **offline**, scores are **stored locally**  
- Once the device reconnects, the game **syncs and uploads pending scores**  
- Ensures player progress is never lost
